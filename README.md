# Kolot · קולות

אפקט מקהלה ל-Logic Pro (AU) ולכל תוכנה שתומכת ב-VST3. שמים אותו על ערוץ של שירה, והערוץ מושר על ידי מקהלה של כ-20 זמרים בזמן אמת, עם אותן מילים, אותה מנגינה ואותו תזמון. אין צורך לגרור קבצים.
מאת אלון מלר.

---

## בנייה (בלי לקמפל על המחשב)

1. פותחים ריפו חדש ב-GitHub (למשל `kolot`) ומעלים אליו את כל התיקייה הזאת, כולל התיקייה הנסתרת `.github`.
2. בלשונית **Actions** הבנייה רצה לבד בכל העלאה, או ידנית דרך **Run workflow**.
3. בסוף הריצה מורידים את **Kolot-dmg** מתחתית העמוד. בתוך ה-zip נמצא `Kolot-2.0.0.dmg`.

## התקנה מה-DMG

1. פותחים את `Kolot-2.0.0.dmg` ולוחצים לחיצה כפולה על **Kolot Installer.pkg**.
2. אם macOS אומר שאי אפשר לאמת את המפתח: **הגדרות המערכת ← פרטיות ואבטחה**, גוללים למטה ולוחצים **"פתח בכל זאת"**.
3. המתקין שם את:
   - ‏AU ב-`/Library/Audio/Plug-Ins/Components`
   - ‏VST3 ב-`/Library/Audio/Plug-Ins/VST3`
   - אפליקציה עצמאית ב-`/Applications`
4. ב-Logic Pro, בערוץ השירה, לוחצים על משבצת **Audio FX** ובוחרים **Audio Units ← Alon Meller ← Kolot**.
   אם הפלאגין לא מופיע: **Logic Pro ← Settings ← Plug-in Manager ← Reset & Rescan Selection**.

## עבודה

1. **מכניסים:** בערוץ אודיו עם שירה, לוחצים על משבצת **Audio FX** ובוחרים **Audio Units ← Alon Meller ← Kolot**.
2. **בוחרים מקהלה:**

   | מקהלה | אופי | טווח |
   |---|---|---|
   | Gospel | קולות גברים ונשים, מלא ונשמתי | E2–G5 |
   | Kids | מקהלת ילדים בהירה | G#2–G5 |
   | Shout | קבוצת גברים לחלקים צעוקים | E2–G5 |

3. **בוחרים מיקרופון:**
   - U67 ו-C12/C24 זמינים בכל המקהלות.
   - Schoeps זמין ב-Gospel וב-Shout.
   - Telefunken זמין ב-Kids.
4. **מעבדים:**
   - **Key** ו-**Scale** קובעים איך ייבנו ההרמוניות.
   - **‎-1 Oct / +1 Oct** מוסיפים קבוצה אוקטבה מתחת או מעל.
   - **3rd / 5th Above/Below** מוסיפים טרצה או קווינטה דיאטונית לפי הסולם.
   - **Stereo / Mono** קובע אם הזמרים פרושים על פני הסטריאו או מרוכזים במרכז.
5. **מלטשים:** Low Cut, ‏Brightness, ‏Reverb ו-Output.
   **Mix** קובע את היחס בין הערוץ המקורי למקהלה: ב-0% שומעים רק את הערוץ המקורי, ב-100% רק את המקהלה.
6. כל שינוי נשמע מיד, תוך כדי ניגון.

**חלון LEAD:** מראה איזה תו השירה שרה עכשיו, ואילו תווים המקהלה מוסיפה מעליו ומתחתיו.

**השהיה:** Kolot מקשיב כ-100 מילישניות קדימה כדי לנתח לפני שהוא שר. Logic מפצה על זה אוטומטית בניגון, כך שהמקהלה מסונכרנת לשיר. בזמן הקלטה עם האפקט פועל תשמע השהיה קטנה, ולכן עדיף להקליט בלי Kolot ולהוסיף אותו אחר כך.

**טיפ:** שירה יבשה ומונופונית, בלי ריוורב לפני Kolot, נותנת את התוצאה הטובה ביותר.

## איך זה עובד, ובמה זה שונה מ-I AM CHOIR

Kolot כולל את כל הפקדים של I AM CHOIR, אבל עובד כאפקט חי ולא כמכשיר שמייצר קובץ, ומנוע הצליל שלו שונה.
I AM CHOIR משתמש במודלים של בינה מלאכותית שאומנו על הקלטות של זמרים מסוימים. Kolot יוצר את המקהלה בעיבוד אותות (DSP), בזמן אמת:
- מזהה את גובה הצליל של השירה תוך כדי ניגון (YIN).
- מפרק אותה למחזורים (PSOLA).
- בונה מכל מחזור כ-20 זמרים, ולכל אחד מהם:
  - כיוון מעט שונה, סחיפה איטית וויברטו משלו.
  - "גודל קול" אחר (הזזת פורמנטים: ילדים, נשים, גברים).
  - איחור קטן בתזמון.
  - מיקום משלו בסטריאו.
- מוסיף מיקרופון, חדר וריוורב.

התוצאה היא מקהלה מהקול שלך. היא לא נשמעת כמו זמרים אחרים שמחליפים אותך.

## מנוע AI (בהמשך)

את מנוע הצליל, `RealtimeChoir`, אפשר להחליף. אפשר להוסיף `NeuralChoirEngine` שמריץ מודל המרת קול בקוד פתוח (RVC או Neutone), מאומן על הקלטות שבבעלותך, למשל מקהלה שתקליט בעמותה בהסכמת הזמרים. 

## למפתחים

- בנייה מקומית ב-Mac:
  `cmake -B build -G Xcode && cmake --build build --config Release`
- כלי בדיקה משורת הפקודה (מריץ קובץ דרך המנוע בבלוקים, כמו Logic):
  `-DKOLOT_BUILD_CLI=ON`, ואז `kolot-render in.wav out.wav gospel 0 0 "od 3u"`
- תמונת הרקע מצוירת בקוד: `python3 tools/make_background.py`. אפשר להחליף את `Resources/background.jpg` בתמונה משלך.
- מבנה הקוד:

  | קובץ | תפקיד |
  |---|---|
  | `RealtimeChoir` | ניתוח השירה ויצירת המקהלה בזמן אמת |
  | `LiveFinisher` | מיקרופון, חדר, אקולייזר, ריוורב ו-Mix |
  | `PluginProcessor` | פרמטרים, עיבוד אודיו ושמירה |
  | `PluginEditor` + `KolotLookAndFeel` | הממשק |
