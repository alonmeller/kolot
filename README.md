# Kolot · קולות

פלאגין מקהלה ל-Logic Pro (AU) ולכל תוכנה שתומכת ב-VST3. נותנים לו שירה אחת, והוא מחזיר אותה מושרת על ידי מקהלה של כ-20 זמרים, עם אותן מילים, אותה מנגינה ואותו תזמון.
מאת אלון מלר.

---

## בנייה (בלי לקמפל על המחשב)

1. פותחים ריפו חדש ב-GitHub (למשל `kolot`) ומעלים אליו את כל התיקייה הזאת, כולל התיקייה הנסתרת `.github`.
2. בלשונית **Actions** הבנייה רצה לבד בכל העלאה, או ידנית דרך **Run workflow**.
3. בסוף הריצה מורידים את **Kolot-dmg** מתחתית העמוד. בתוך ה-zip נמצא `Kolot-1.0.0.dmg`.

## התקנה מה-DMG

1. פותחים את `Kolot-1.0.0.dmg` ולוחצים לחיצה כפולה על **Kolot Installer.pkg**.
2. אם macOS אומר שאי אפשר לאמת את המפתח: **הגדרות המערכת ← פרטיות ואבטחה**, גוללים למטה ולוחצים **"פתח בכל זאת"**.
3. המתקין שם את:
   - ‏AU ב-`/Library/Audio/Plug-Ins/Components`
   - ‏VST3 ב-`/Library/Audio/Plug-Ins/VST3`
   - אפליקציה עצמאית ב-`/Applications`
4. ב-Logic Pro פותחים ערוץ **Software Instrument** ובוחרים **AU Instruments ← Alon Meller ← Kolot**.
   אם הפלאגין לא מופיע: **Logic Pro ← Settings ← Plug-in Manager ← Reset & Rescan Selection**.

## עבודה

1. **מכניסים שירה:** גוררים קובץ שירה יבש ומונופוני לאזור העליון, או לוחצים כדי לבחור קובץ. עדיף טייק אחד, בלי דאבלים, בלי הרמוניות ובלי ריוורב.
2. **בוחרים מקהלה:**

   | מקהלה | אופי | טווח |
   |---|---|---|
   | Gospel | קולות גברים ונשים, מלא ונשמתי | E2–G5 |
   | Kids | מקהלת ילדים בהירה | G#2–G5 |
   | Shout | קבוצת גברים לחלקים צעוקים | E2–G5 |

3. **בוחרים מיקרופון:**
   - U67 ו-C12/C24 זמינים בכל המקהלות.
   - Schoeps זמין ב-Gospel וב-Shout.
   - Telefunken זמין ב-Kids.
4. **מעבדים:**
   - **Key** ו-**Scale** קובעים איך ייבנו ההרמוניות.
   - **‎-1 Oct / +1 Oct** מוסיפים קבוצה אוקטבה מתחת או מעל.
   - **3rd / 5th Above/Below** מוסיפים טרצה או קווינטה דיאטונית לפי הסולם.
   - **Stereo / Mono** קובע אם הזמרים פרושים על פני הסטריאו או מרוכזים במרכז.
5. לוחצים **Create Vocals**.
6. **מלטשים:** Low Cut, ‏Brightness, ‏Reverb ו-Output מתעדכנים מיד, בלי ליצור מחדש.
   שינוי של מקהלה, סולם, אוקטבות או הרמוניות דורש לחיצה על **Update Vocals**.
7. **מוציאים את המקהלה:** גוררים את **Drag choir to a track** לערוץ אודיו ב-Logic.
   אפשר גם ללחוץ **Preview** כדי לשמוע, או **Export...** כדי לשמור קובץ.
   כל הקבצים נשמרים גם ב-`~/Music/Kolot/Renders`.

טיפ: למקהלה גדולה במיוחד מפעילים גם ‎-1 Oct וגם ‎+1 Oct.

## איך זה עובד, ובמה זה שונה מ-I AM CHOIR

Kolot משחזר את תהליך העבודה ואת כל הפקדים של I AM CHOIR, אבל מנוע הצליל שלו שונה.
I AM CHOIR משתמש במודלים של בינה מלאכותית שאומנו על הקלטות של זמרים מסוימים. Kolot יוצר את המקהלה בעיבוד אותות (DSP):
- מזהה את גובה הצליל של השירה (YIN).
- מפרק אותה למחזורים (PSOLA).
- בונה מכל מחזור כ-20 זמרים, ולכל אחד מהם:
  - כיוון מעט שונה, סחיפה איטית וויברטו משלו.
  - "גודל קול" אחר (הזזת פורמנטים: ילדים, נשים, גברים).
  - איחור קטן בתזמון.
  - מיקום משלו בסטריאו.
- מוסיף מיקרופון, חדר וריוורב.

התוצאה היא מקהלה מהקול שלך. היא לא נשמעת כמו זמרים אחרים שמחליפים אותך.

## מנוע AI (בהמשך)

הממשק `ChoirEngine` ב-`Source/ChoirEngine.h` מוכן להחלפת מנוע. אפשר להוסיף `NeuralChoirEngine` שמריץ מודל המרת קול בקוד פתוח (RVC או Neutone), מאומן על הקלטות שבבעלותך, למשל מקהלה שתקליט בעמותה בהסכמת הזמרים. אחרי זה מחליפים את `createDefaultEngine()`.

## למפתחים

- בנייה מקומית ב-Mac:
  `cmake -B build -G Xcode && cmake --build build --config Release`
- כלי בדיקה משורת הפקודה:
  `-DKOLOT_BUILD_CLI=ON`, ואז `kolot-render in.wav out.wav gospel 0 0 "od 3u"`
- מבנה הקוד:

  | קובץ | תפקיד |
  |---|---|
  | `ChoirEngine` | ניתוח ויצירת המקהלה |
  | `Finisher` | מיקרופון, חדר, אקולייזר וריוורב |
  | `PluginProcessor` | פרמטרים, עבודה ברקע, השמעה ושמירה |
  | `PluginEditor` + `KolotLookAndFeel` | הממשק |
