Kolot · קולות — Choir Engine by Alon Meller

1. Double-click "Kolot Installer.pkg" and follow the steps.
   If macOS says it can't verify the developer:
   System Settings -> Privacy & Security -> scroll down -> "Open Anyway".
2. Installed to:
   /Library/Audio/Plug-Ins/Components/Kolot.component   (AU - Logic Pro)
   /Library/Audio/Plug-Ins/VST3/Kolot.vst3
   /Applications/Kolot.app                              (standalone)
3. Logic Pro: new Software Instrument track -> AU Instruments -> Alon Meller -> Kolot
   Not listed? Logic Pro -> Settings -> Plug-in Manager -> Reset & Rescan Selection.

התקנה: לחיצה כפולה על Kolot Installer.pkg.
אם macOS חוסם: הגדרות המערכת ← פרטיות ואבטחה ← "פתח בכל זאת".
ב-Logic: ערוץ Software Instrument ← AU Instruments ← Alon Meller ← Kolot
